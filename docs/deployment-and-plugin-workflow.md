# Deployment and Project Plugin Workflow

## Goals

This repository now supports a project-level Unreal deployment workflow:

- Python-side authoring, conversion, training, and ONNX export stay in this repo.
- Unreal-side inference lives in a project plugin, not in the engine.
- Model bundles are copied into the plugin resources for distribution.

## Directory layout

- `unreal/AI4AnimationNNE/`
  - Source-of-truth Unreal plugin template.
- `Artifacts/UE/<package-name>/`
  - Exported ONNX package directories generated by Python.
- `scripts/`
  - Batch wrappers for bootstrap, export, deploy, build, and editor launch.

## Batch entrypoints

- `scripts/bootstrap_env.bat`
  - Creates `.venv` inside the repo and installs all runtime/export dependencies.
- `scripts/export_ue_bundle.bat`
  - Exports the sample locomotion checkpoint to ONNX plus a UE manifest.
- `scripts/deploy_ue_plugin_to_nne_t.bat`
  - Copies the plugin and model packages into `D:\PCG_ANIM_RL\NNE_T\Plugins\AI4AnimationNNE`.
- `scripts/build_nne_t_editor.bat`
  - Builds the target project with the deployed plugin.
- `scripts/open_nne_t_editor.bat`
  - Opens the Unreal editor for the target project.
- `scripts/oneclick_nne_t.bat`
  - Runs the whole chain end to end.

## Plugin runtime surface

The Unreal plugin currently exposes:

- `UAI4AnimationNNEProjectSettings`
  - Project-level defaults for package root, runtime name, and default package.
- `UAI4AnimationNNESubsystem`
  - Runtime loader for manifest + ONNX file and synchronous CPU inference through NNE.
- `UAI4AnimationNNEBlueprintLibrary`
  - Blueprint access to the subsystem.

## Package contract

Each model package directory should contain:

- `<package-name>.onnx`
- `<package-name>.ue.json`
- optional `<package-name>.metadata.json`

The manifest stores:

- runtime name
- skeleton contract
- compatible source formats (`npz`, `bvh`)
- retargeting expectations
- terrain support expectations
- model I/O metadata when available

## Intended runtime split

Python side:

- source motion conversion
- dataset preparation
- training
- ONNX export
- manifest generation

Unreal side:

- NNE inference
- retargeting
- Motion Matching
- IK/FK and morph post-process
- terrain-aware runtime locomotion adaptation
